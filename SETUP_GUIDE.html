GitHub Pages Setup Guide

One-time setup — takes about 10 minutes. After that, updates take 30 seconds.

1 Create a free GitHub account

Go to github.com and click Sign up. Use any email address — your GitHub username will appear in your toolkit URL, so choose something professional (e.g. joshcoppolelli).

Verify your email when prompted. That's it — GitHub is free forever for public pages.

2 Create a new repository
  1. Once logged in, click the + icon in the top right corner → New repository
  2. Name it exactly: broker-toolkit (lowercase, with hyphen)
  3. Set it to Public (required for free GitHub Pages)
  4. Tick "Add a README file"
  5. Click Create repository
⚠️ The repository name matters — it becomes part of your URL. Use broker-toolkit exactly.
3 Upload your files
  1. On your new repository page, click Add file → Upload files
  2. Drag and drop all four files from the folder Claude gave you:
    • index.html — the dashboard
    • anniversary_email_generator.html
    • post_contact_email_generator.html
    • SETUP_GUIDE.html — this file (optional to upload)
  3. Scroll down, leave the commit message as-is, and click Commit changes
4 Turn on GitHub Pages
  1. On your repository page, click Settings (top tab)
  2. In the left sidebar, click Pages
  3. Under Source, select Deploy from a branch
  4. Under Branch, select main and keep the folder as / (root)
  5. Click Save

Wait about 60 seconds, then refresh the page. GitHub will show you your live URL:

https://YOUR-USERNAME.github.io/broker-toolkit
✅ That URL is now permanent. Bookmark it. Share it with anyone you want to have access to the tools.
5 How to update a tool in the future

Every time Claude builds you an updated file, here's all you do:

  1. Go to github.com and open your broker-toolkit repository
  2. Click on the file you want to replace (e.g. anniversary_email_generator.html)
  3. Click the pencil ✏️ icon (Edit this file) — then scroll down and click the ⋯ menu → Delete file. Commit the deletion.
  4. Back on the main repo page, click Add file → Upload files and drag in the new version
  5. Click Commit changes — it's live in under 60 seconds
💡 Faster method: Click the file → click the pencil icon → in the top right click "..." → Upload file to replace it directly without deleting first.
➕ Adding future tools
When Claude builds a new tool, he'll give you a new HTML file. Just upload it to the repository (Add file → Upload files) and he'll have already updated index.html to link to it. One upload and it appears on your live dashboard automatically.
